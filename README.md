# Corrupt State RP

مشروع لعبة RP ثلاثية الأبعاد للهاتف، مبني كبداية قابلة للتشغيل بدون سيرفر.

## المرحلة الحالية
- عالم مدينة ثلاثي الأبعاد مولد برمجيًا.
- شخصية قابلة للتحكم.
- كاميرا منظور ثالث.
- تحكم لمس + لوحة مفاتيح.
- HUD عربي.
- المال / XP / المستوى.
- الجوع والعطش.
- نظام مهام أولي.
- تفاعل، مركبة تجريبية، جرد، فصائل واستراحة.
- إعدادات Android قابلة للتصدير.

## الاتجاه
المشروع سيكبر تدريجيًا إلى أنظمة Corrupt State RP الواردة في وثيقة التصميم: الوظائف، المركبات، الفصائل، العصابات، الشرطة، الجيش، الطب، الحكومة، القضاء، السجون، الاقتصاد، العقارات والإدارة.

> لا ننسخ أصول OneState أو GTA. المرجع هو مستوى تجربة الـMobile Open World RP فقط، مع أصول مرخصة أو مجانية عند إضافتها.
